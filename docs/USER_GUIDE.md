# Keystone user guide

## Sign in

Keystone restores a valid secure session automatically when you return. Use **Sign out** on a shared device. Passwords are never displayed; if Caps Lock is enabled while entering one, Keystone shows a short warning beside the password field.

## Finding help

Open **How Keystone works** from the navigation, then use **Search help topics** to filter terms and step-by-step guides. Search matches topic names, explanations and task steps. Every guide entry has its own link, so you can share the exact explanation with a teammate.

## Skill map

The Skill map has Network, Matrix and Charts views. **Matrix** is the heat-map view: rows are people, columns are skills, and each coloured cell shows the recorded proficiency level. Use the department, minimum-level and concentrated-skill filters to focus the map. Colours are supported by visible levels and labels; do not infer a result from colour alone.
